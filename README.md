🌿 Vida Paz — Complejo de Cabañas
Sitio web oficial del complejo de cabañas Vida Paz, ubicado en Traslasierra, Córdoba, Argentina.

📋 Descripción
Página web desarrollada desde cero con HTML, CSS y JavaScript puro. Diseño moderno, elegante y completamente responsive para mobile y desktop.

✨ Funcionalidades

Header fijo con logo y navegación que cambia al hacer scroll
Hero con foto de fondo y efecto parallax
Galería de paisajes deslizable con arrastre de mouse y táctil
Sección de cabañas con modal interactivo y carrusel de fotos
Sección de información con servicios, espacios y políticas de reserva
Mapa de ubicación embebido con Google Maps
Reseñas de Google con diseño en tarjetas
Sección Conócenos con historia del complejo y datos destacados
Banner de Instagram con link directo al perfil
Footer completo con navegación, contacto y redes sociales
Botón flotante de WhatsApp con mensaje predefinido
Animaciones al hacer scroll con Intersection Observer
Diseño responsive para celular, tablet y desktop


🛠️ Tecnologías utilizadas

HTML5
CSS3 (Grid, Flexbox, Variables CSS, Media Queries)
JavaScript vanilla (sin frameworks)
Google Maps Embed API
Google Fonts (Raleway)
